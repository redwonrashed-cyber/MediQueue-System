# MediQueue - Medical Appointment & Queue Management System

A web-based system for managing patient appointments, doctor schedules,
and queue tokens, built with plain HTML, CSS and JavaScript
(localStorage used as a mock database for demo purposes).

## Modules
- Authentication (Login / Role-based access)
- Appointment Booking
- Queue Management
- Doctor Schedule Management
- Patient Records
- Admin Dashboard & Reports

## How to run
Open `index.html` in a browser. No server/build step required.
